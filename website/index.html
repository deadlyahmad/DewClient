SUPPORT

Frequently asked questions

Which Minecraft versions support DewCosmetics?

DewCosmetics 0.4.0 supports Fabric on Minecraft 1.21.4, 1.21.8, 1.21.11, 26.2, and 26.3. The launcher installs or updates the matching mod when preparing a supported instance. Cross-version cosmetics appear between players running DewCosmetics on those versions.

How do I use a claimed cape?

Claim the free cape from Cosmetics, then choose Equip. The launcher shows which cape is active and syncs the selection to the game.

How does sign-in work?

Microsoft sign-in uses Microsoft’s official flow. Discord sign-in creates a separate DewClient profile. Linking Discord to a Microsoft profile verifies community membership; it does not grant access to the other account.

Is DewClient free?

Yes. DewClient is free to download and use. Minecraft must be owned separately for Microsoft profiles.
