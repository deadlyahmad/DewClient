# DewClient project status

**Maintainer / developer:** Fateh  
**Status date:** 10 October 2026  
**Status:** Retired; source archive for independent forks

DewClient is being released as source code for the community to inspect, learn from, modify, and use as the basis of an independently branded client.

- **No further official DewClient updates are planned.**
- **Previously released/legacy update downloads have been disconnected from the official server**, as announced by the maintainer.
- Features that depend on DewClient-operated APIs, account services, manifests, downloads, cosmetics, Discord configuration, or other hosted infrastructure may no longer work. Publishing this source does not mean those services are online or supported.
- There is no commitment to provide future maintenance, security fixes, compatibility updates, or hosted services for this archived project.
- Independent forks must use infrastructure they control and should not point users at retired official endpoints or imply official support.

The code license and the reserved DewClient branding are explained in [`COPYING.md`](./COPYING.md). Open-source code reuse does not grant permission to reuse the official product identity.
